🐇 Rabbit Hole Wiki - Полная документация проекта
🎯 Суть проекта
Rabbit Hole Wiki — это интерактивная платформа для визуального исследования знаний через графовые связи между концепциями. Вместо линейной навигации (как в Википедии), пользователь погружается в "кроличью нору" взаимосвязанных идей, открывая неожиданные связи между разными областями знаний.

Ключевая метафора
Интернет — это бесконечная кроличья нора (rabbit hole). Эта платформа делает её видимой, навигабельной и игровой.

🧠 Философия проекта
1. Знание как сеть, а не иерархия
Каждая статья (концепция) — узел в графе

Связи между статьями — рёбра с типами и силой

Нет "верха" и "низа", есть только связи

2. Процесс важнее результата
Ценность в путешествии, а не в достижении цели

"Заблудиться с интересом" — главный сценарий

Случайные открытия ценнее запланированных

3. Игрофикация познания
Поиск знаний как игра

Баллы за нахождение связей

Прогресс как "карта исследованных территорий"

🎮 Основные механики
1. Режим "Свободное падение" (Free Fall)
text
Пользователь → Случайная статья → Исследование связей → Новая статья
Начало со случайной точки

Клик по связанной концепции → "проваливание" в неё

Визуализация пути как туннеля

2. Режим "Мост между мирами" (Bridge Builder)
text
Задача: Связать "Философию" и "Квантовую физику"
Игрок ищет цепочку: Философия → Наука → Физика → Квантовая физика
Победа: Минимальное число переходов
3. Режим "Карта знаний" (Knowledge Map)
Визуализация всех посещённых статей

"Территории" по категориям

Редкие области как "неисследованные земли"

4. AI-помощник "Проводник" (The Guide)
Предлагает неочевидные связи

"Знаете ли вы, что философия стоицизма связана с когнитивно-поведенческой терапией?"

Генерирует интересные факты о связях

WHERE NOT (user)-[:VISITED]->(recommended)
RETURN recommended
ORDER BY COUNT(*) DESC
LIMIT 5
